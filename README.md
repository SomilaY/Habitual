# Habitual

Habitual is a native habit tracker for iPhone, built with SwiftUI and SwiftData. Create daily habits, check them off, follow your consistency, and build streaks over time.

## Features

- **Today dashboard** with daily progress, completion stats, and current streaks
- **Habit details** with streak history, completion statistics, a consistency heat map, milestones, and reminder settings
- **Insights** with completion trends, average completion, and streak analytics
- **Calendar** heat map for viewing activity across habits or focusing on one habit
- **Achievements** that unlock as you build habits and complete check-ins
- **Daily notifications** at a time you choose, with an action to mark a habit done
- **Siri and Shortcuts** actions to complete a habit and check today's progress
- **Dark appearance** and a custom glass-inspired interface

## Getting started

1. Open the Habitual Xcode project or workspace.
2. Choose an iOS simulator or connected device.
3. Build and run the **Habitual** app target.

Habits and achievements are stored locally with SwiftData. Notification permission is requested when you enable a reminder. If permission is denied, you can manage notification access in the device's Settings app.

## Using Habitual

- Add a habit from the **Today** tab with the plus button.
- Tap a habit's completion control to check it off for today; open its card for streaks, history, and reminder settings.
- Visit **Insights**, **Calendar**, and **Trophies** to review trends, activity, and achievements.
- Use the Habitual actions in Siri or the Shortcuts app to complete a habit or ask about today's progress.
